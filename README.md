# 🛒 Market Basket Analysis

## 📌 Overview
This project analyzes transaction data to find products frequently bought together using the Apriori algorithm.

## 🧰 Tools Used
- Python (Pandas, Mlxtend)
- Jupyter Notebook
- Association Rule Mining

## 🔍 Insights
- Identified frequent product pairs
- Provided actionable bundling strategies
- Suggested cross-selling opportunities

## 📁 How to Run
1. Clone the repo
2. Run `notebooks/market_basket_analysis.ipynb`
